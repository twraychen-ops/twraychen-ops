# 我的方法論

> 用最簡的道，挑最對的器，造能交棒的系統。

三句話，是一條遞進的路：**簡是入口，器是路徑，傳承是終點。**

---

## 一、道 — 大道至簡

**心法：決定做什麼、不做什麼。**

複雜不是能力的證明，簡潔才是。真正的簡，不是做得少，是看穿哪些複雜是多餘的。

當一件事讓我「愈改愈煩躁」，那是「道」在提醒：系統偏離了簡。刪掉炫技的外殼，退回到一句話能說清的核心——那不是退步，是想通了。

> 能用最少的東西解決真實的問題，是更高階的設計，不是偷懶。

---

## 二、器 — 工欲善其事，必先利其器

**方法：決定用什麼做。**

每一件事，先問一句：**這需要自己造嗎？還是善用現成的？**

真正的利器，是認出別人已經磨好的刀，不是自己重鑄一把。不自己蓋資料庫，用現成的；不自己寫系統，用對的工具。並且，會依任務的性質挑對的器——靜態的資料一種器，動態的資料另一種器。

> 磨刀不誤砍柴工。認對工具，事就成了一半。

---

## 三、承 — 建造可傳承系統

**目的：決定為什麼做。**

做每一件事，不只想「我自己用」，而是「能不能交棒」。

傳給孩子、傳給夥伴、傳給下一代。可傳承不只是技術上能複製，是**價值觀上值得複製**。所以收束時要回頭校準本源，怕簡化之後失了真——因為傳承的是原則，不是空殼。

> 設計的最高目的，是讓好的東西活得比自己久。

---

## 三句如何彼此校驗

- 不夠**簡**的，傳不下去 —— 太複雜，別人學不會。
- **器**不對，簡也做不到 —— 硬造輪子，必然臃腫。
- 心裡沒有**傳承**，就會為炫技而複雜 —— 傳承反過來逼你簡。

三句是一個閉環，不是三條平行線。每個決定，都有尺可量。
