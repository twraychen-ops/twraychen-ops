### 道　大道至簡

決定做什麼，更決定不做什麼。

真正的簡不是做得少，是看穿哪些複雜是多餘的。
當一件事愈改愈煩躁，那是提醒：它偏離了簡。

<br>

### 器　工欲善其事，必先利其器

做之前先問：這需要自己造嗎？

利器，是認出別人磨好的刀，不是自己重鑄一把。
靜態的資料一種器，動態的資料另一種——器隨事而變。

<br>

### 承　建造可傳承系統

不只想我自己用，而是能不能交棒。

可傳承，不是技術上能複製，是價值上值得複製。
所以簡化時要回望本源——傳下去的是原則，不是空殼。

<br>
